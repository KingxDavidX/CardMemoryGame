## Installation Guide
To install and play the game, simply pull the repository and either compile and run, or simply run using Java CLI.

### Prerequisites
- Java 

### Installation
1. Pull repository
2. In project source directory, run `javac main.java`
3. Execute compiled program with `java CardMemoryGame`
